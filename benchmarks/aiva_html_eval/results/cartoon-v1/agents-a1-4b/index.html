AIVA / Grace Architecture

A visual simulation of how the conversational AI system processes your request.

Step 0

User composes message at Console.

Step 1

Console encodes signal & sends via ROS.

Step 2

Receptor decodes & hands to Interactive.

Step 3

Interactive assembles persona & Memory.

Step 4

Router runs Nymphaea RP & streams reply.

Step 5

Response returns, Console decodes stream.

Step 6

Memory saves exchange & shows summary.

Step 0: User Input

Optional Capabilities (Sidecar)

Canvas & Imaging

Supports drawing and rendering assets.

MOSS

Optional raster painting sidecar for visual output.

* This visualization is a simulation, not live telemetry. AIVA does not launch AuRoRA's CNC/TMS robot stack.
